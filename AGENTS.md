# AGENTS.md — Avto Yuvish (Car Wash Tracker)

Static single-page web app. No build system, no package manager, no server. Open `index.html` directly in browser.

## Commands
- No build/test/deploy commands exist. Edit HTML/CSS/JS, reload browser.
- Print receipt: `hisobYaratish()` then `window.print()`; `.no-print` hidden, `#receipt` shown via `@media print`.

## Architecture
- `index.html` — single-page layout with cards (services, add car, car list, receipt)
- `app.js` — all logic: data model (`xizmatlar`, `avtomobillar`), formatting (`formatPlate`, `narxFormat`, `vaqtniFormatlash`), localStorage persistence (`cw_xizmatlar`, `cw_avtomobillar`)
- `styles.css` — CSS variables (`--accent: #2d6a4f`), responsive breakpoints, print styles

## Key Patterns / Gotchas
- All state in memory arrays persisted to `localStorage`; no backend.
- Uzbek locale (`uz-UZ`) used everywhere: dates, numbers, currency (`so'm`), plate formatting.
- `formatPlate()` handles two plate formats: `01 A 123 AA` (letter-first rest) and `01 123 AAA` (digit-first rest). Uses `selectionStart/End` preservation during input.
- `AVTOMOBIL_MODELLARI` array sorted and embedded; rendered into `<datalist>`.
- Receipt generated by mapping `avtomobillar` array; total computed via `reduce` over service prices.
- `service-select` rebuilt on every service edit; index-based lookup (`xizmatIndex`) links cars to services. Changing/deleting services updates receipts via index reference, not name.
- No framework; pure DOM manipulation with `innerHTML` templates and inline `onclick` handlers.
- Print CSS: `body { background: white; padding: 0; }`, `#receipt { display: block !important; }`, `.no-print { display: none !important; }`.

## Data Flow
`avtomobilQoshish()` pushes to `avtomobillar` → `saqlash()` to localStorage → `avtomobillarKorsatish()` renders list → `hisobYaratish()` builds receipt HTML and scrolls to it.
